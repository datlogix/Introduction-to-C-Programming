# Module 1 Project — Fortune Teller / Compliment Generator

Remember the hook from the top of this module's README? You're building
your own version now, using **only** `printf` and comments — nothing
else you've learned yet is required.

## Requirements

Your program must:

1. Print at least **8 lines** of output total.
2. Include **at least one "reveal" moment** like the hook did — a line
   built from two or more separate `printf` calls that only makes sense
   once they're read together (no `\n` between them until the reveal).
3. Include **at least two comments**: one explaining a genuine reason
   behind a choice you made (not just restating the code).
4. Be personalized — use your own name, a friend's name, or an in-joke.
   Generic placeholder text defeats the point.

## Ideas if you're stuck

- A fortune-teller that "predicts" something obviously true, played
  straight (like the hook).
- A dramatic, over-the-top "compliment generator."
- An ASCII art greeting card for a friend or family member.
- A fake "loading..." sequence that ends in a joke.

## Getting started

Open [`starter.c`](starter.c) and build inside `main()`. Compile and run
often — don't write the whole thing before testing your first line.

```bash
gcc starter.c -o fortune
./fortune
```

## Done?
